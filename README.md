# Truffle

추론할 때 과거 캐시(KV)를 **전부 읽지 않는다.** 라우터가 지금 필요한 그룹만 골라
그 그룹의 **원본 KV 를 손실 없이** 읽는다. MoE 가 전문가 가중치를 고르듯 기억을 고른다.

**[→ 설명과 체험](https://rhydcdc.github.io/Truffle/)**

이름은 *트러플*(송로버섯) 사냥에서 왔다. 땅 전체를 파헤치지 않는다. 냄새를 따라 파고, 나오는 동안은 계속 파다가,
더 나오지 않으면 멈춘다 — 라우팅 키로 그룹을 골라 읽고 새로 찾은 정답이 없는 라운드에서 멈추는 이 모델이 하는 일이 그것이다.

## 무엇이 다른가

**KV 압축 · evict 와는 다른 범주다.** 저쪽은 *이미 엉켜 만들어진 캐시를 사후에 줄이는* 문제를 풀고,
이쪽은 *애초에 나눠 읽을 수 있는 캐시가 생기도록 학습시키는* 문제를 푼다.
읽은 그룹은 원본 그대로 읽으므로 추론 경로에 손실이 없고, 안 읽은 그룹은 사라진 게 아니라
**다음 질의가 읽을 수 있다** (evict 는 비가역이다).

## 결과

방 64개 · 질의 32,768개 실측. 정답 개수를 모른 채 시작해 필요한 만큼만 읽는다.

| 읽는 방식 | 전부완수 | 읽기 |
|---|---|---|
| 전부 읽기 | 1.0000 | 100 % |
| **Truffle** | **0.9992** | **31.3 %** |

## 코드

| 파일 | 내용 |
|---|---|
| `src/model.py` | 트랜스포머 · 라우팅 키 · 반복 라우팅 루프(정지 규칙 · q 보정) |
| `src/data.py` | 테스트베드 생성기 |
| `src/train.py` · `src/metrics.py` | 학습 루프 · 손실 4종 · 완수 지표 |
| `web/export.py` | 브라우저용 ONNX 자산 생성 (fp32 — 원본 모델 그대로) |
| `web/demo.js` | 체험 — 모델을 브라우저에서 돌린다 (onnxruntime-web · 서버 없음) |
| `index.html` | 워크스루 + 체험 데모 |
