# shelfmark

추론할 때 과거 캐시(KV)를 **전부 읽지 않는다.** 라우터가 지금 필요한 그룹만 골라
그 그룹의 **원본 KV 를 손실 없이** 읽는다. MoE 가 전문가 가중치를 고르듯 기억을 고른다.

**[→ 직접 그려서 해 보기](https://rhydcdc.github.io/shelfmark/)**

이름은 도서관의 *shelfmark*(청구기호)에서 왔다. 책등의 표식은 내용을 요약하지 않는다.
펼칠지 말지만 정한다 — 캐시 그룹에 붙는 라우팅 키가 하는 일이 정확히 그것이다.

## 무엇이 다른가

**KV 압축 · evict 와는 다른 범주다.** 저쪽은 *이미 엉켜 만들어진 캐시를 사후에 줄이는* 문제를 풀고,
이쪽은 *애초에 나눠 읽을 수 있는 캐시가 생기도록 학습시키는* 문제를 푼다.
읽은 그룹은 원본 그대로 읽으므로 추론 경로에 손실이 없고, 안 읽은 그룹은 사라진 게 아니라
**다음 질의가 읽을 수 있다** (evict 는 비가역이다).

## 결과

방 64개 · 질의 32,768개 실측. 정답 개수를 모른 채 시작해 필요한 만큼만 읽는다.

| | 전부완수 | 읽기 |
|---|---|---|
| 전부 읽기 | 1.0000 | 100 % |
| **shelfmark** | **0.9992** | **31.3 %** |
